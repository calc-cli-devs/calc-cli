# Cómo contribuir
1. Haz fork del repo y clónalo.
2. Crea una rama desde `main` actualizada: `feature/<nombre>` o `fix/<nombre>`.
3. Commits con formato: `feat: ...`, `fix: ...`, `test: ...`, `docs: ...`.
4. Asegúrate de que `pytest` y `ruff check .` pasan.
5. Abre un PR hacia `main` enlazando el issue (`Closes #N`).
